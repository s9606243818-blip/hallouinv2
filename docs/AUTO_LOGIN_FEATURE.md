# 💾 Автовход: Сохранение никнейма

## 📅 Дата: 29.10.2025

---

## ✨ Новая функция: Автоматический вход

**Проблема:**
- После обновления страницы нужно заново вводить никнейм
- На мобильных это особенно неудобно

**Решение:**
- Сохраняем никнейм и аватар в `localStorage`
- Автоматически входим при загрузке страницы
- Добавлена кнопка "Выйти" для смены никнейма

---

## 🎮 Как это работает

### 1. Первый вход

```
1. Открываешь игру
2. Вводишь никнейм "Игрок123"
3. Нажимаешь "Войти в игру"
4. ✅ Никнейм сохраняется в localStorage
```

### 2. После обновления страницы

```
1. Обновляешь страницу (F5 / Ctrl+R)
2. 🚀 Автоматический вход за 0.5 секунды
3. ✅ Ты уже в игре с тем же никнеймом
4. ✅ Аватар тоже сохранился
```

### 3. Смена никнейма

```
1. Нажимаешь "🚪 Выйти"
2. Подтверждаешь выход
3. Страница перезагружается
4. Можешь ввести новый никнейм
```

---

## 🔧 Технические детали

### localStorage

Сохраняются 3 параметра:

```javascript
localStorage.setItem('playerNickname', 'Игрок123');
localStorage.setItem('playerAvatar', '/avatars/photo.jpg');
localStorage.setItem('autoLogin', 'true');
```

### Автовход

```javascript
// При загрузке страницы
const savedNickname = localStorage.getItem('playerNickname');
const autoLogin = localStorage.getItem('autoLogin');

if (savedNickname && autoLogin === 'true') {
  // Автоматический вход через 0.5 сек
  setTimeout(() => {
    socket.join(savedNickname, savedAvatar);
  }, 500);
}
```

### Выход

```javascript
// При нажатии "Выйти"
localStorage.setItem('autoLogin', 'false');
location.reload();
```

## 🔒 Безопасность

### Что НЕ сохраняется

- ❌ Пароли (их нет в игре)
- ❌ Сессии (каждый раз новое подключение)
- ❌ История игры (только на сервере)
- ❌ Другие игроки (только свой никнейм)

### Что сохраняется

- ✅ Никнейм (публичный)
- ✅ Путь к аватару (публичный)
- ✅ Флаг автовхода (локальный)

### localStorage безопасен

```javascript
// Только в текущем браузере на этом устройстве
// Не передаётся на другие устройства
// Не виден другим пользователям
```
