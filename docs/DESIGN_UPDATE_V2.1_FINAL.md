## 🎯 Что даёт `flex: 1 1 40%`?

### На широком экране (Desktop):
- Элементы занимают **40% ширины**
- В одной строке помещается **2-3 элемента** (вместо строго 2)
- Меньше пустого пространства справа

### Расчёт:
```
┌─────────────────────────────────────────────────────┐
│ [===== 40% =====] gap [===== 40% =====] gap [10%] │
│    HP: 100            EXP: 0                       │
└─────────────────────────────────────────────────────┘
```

Если экран узкий:
```
┌─────────────────────┐
│ [===== 40% =====]   │  HP: 100
│ [===== 40% =====]   │  EXP: 0  
│ [===== 40% =====]   │  LVL: 1
│ [===== 40% =====]   │  Likes: 0
└─────────────────────┘
```

## 💡 Преимущества нового дизайна

### ✅ Компактность
- Статистика занимает меньше места
- Больше пространства для других элементов
- Нет огромных пустых областей

### ✅ Адаптивность  
- На широких экранах: 2-3 элемента в ряд
- На средних: 2 элемента
- На узких: 1 элемент
- Всё автоматически!

### ✅ Читаемость
- Текст остаётся читаемым
- Хорошие пропорции между лейблом и значением
- `white-space: nowrap` предотвращает перенос

### ✅ Визуальная гармония
- Элементы выглядят компактно
- Меньше отвлекающего пространства
- Лучше баланс на странице
