# 🎯 Улучшение UX заданий

## 📝 Что изменено

### 1. **Активные задания перемещены выше**
```
До:
├── Карты действий
├── Карты ролей
└── Активные задания  ← Внизу

После:
├── Активные задания  ← Вверху!
├── Карты действий
└── Карты ролей
```

**Почему:** Задания важнее - их нужно видеть сразу

---

### 2. **Автопрокрутка к заданиям**
При получении нового задания:
1. 📜 Страница плавно прокручивается к заданиям
2. ✨ Секция подсвечивается на 2 секунды
3. 👀 Пользователь сразу видит новое задание

---

### 3. **Аватар, имя и роль в один ряд**
```html
<div class="player-info">
  <h3>Имя</h3>
  <div class="player-role">Роль</div>
  <label class="avatar-upload-btn">📷 Загрузить</label>
</div>
```

**Результат:**
```
[Аватар] Имя 🎭 Дилер 📷 Загрузить  ← Всё в одну строку!
```

---

## 🎬 Как работает автопрокрутка

### Логика срабатывания:

```javascript
renderActiveTasks(tasks) {
  const previousTasksCount = container.querySelectorAll('.task-card').length;
  
  // Рендерим новые задания
  tasks.forEach(task => {
    container.appendChild(createTaskElement(task));
  });
  
  // Если появились НОВЫЕ задания
  if (tasks.length > previousTasksCount) {
    this.scrollToTasks();  // Прокручиваем!
  }
}
```

### Когда срабатывает:
✅ Вы отправили карту кому-то → прокрутка к вашим заданиям  
✅ Вам пришло задание → прокрутка к новому заданию  
✅ Роль приняла запрос → прокрутка к заданию  

### Когда НЕ срабатывает:
❌ Задания просто обновились (без новых)  
❌ Задание завершено (количество уменьшилось)  
❌ Страница просто перезагрузилась

#### 2. **`public/js/modules/tasksUI.js`**

Добавлена функция автопрокрутки:

```javascript
scrollToTasks() {
  const tasksContainer = getElement('activeTasks');
  const cardsBlock = tasksContainer.closest('.cards-block');
  
  setTimeout(() => {
    // Плавная прокрутка
    cardsBlock.scrollIntoView({ 
      behavior: 'smooth', 
      block: 'start'
    });
    
    // Подсветка
    const section = tasksContainer.closest('.cards-section');
    section.classList.add('highlight');
    
    setTimeout(() => {
      section.classList.remove('highlight');
    }, 2000);
  }, 100);
}
```

### ✅ Для UX:
- **Понятнее** - задания сразу видны
