# 🎨 Унификация отступов и адаптивности

## ✅ Исправлено для единообразия

### 1. **Основной блок игрока** - уменьшен gap

```css
.player-block {
  display: flex;
  flex-direction: column;
  gap: var(--gap-md);  /* Было: var(--gap-lg) */
}
```

**Результат:** Меньше расстояние между секциями профиля игрока

---

### 2. **Адаптивность на планшетах** - статистика остаётся 40%

```css
@media (max-width: 768px) {
  .player-stats .stat {
    flex: 1 1 40%;      /* Было: 1 1 100% */
    padding: 8px 10px;  /* Было: 8px 12px */
  }
}
```

**Результат:** 
- На планшетах статистика тоже в 2 колонки (как на десктопе)
- Чуть меньше padding для компактности
- В 1 колонку переходит только на мобильных (≤480px)

---

## 📊 Размеры gap

| Переменная | Значение | Когда используется |
|------------|----------|-------------------|
| `--gap-sm` | 8px | Мелкие отступы |
| `--gap-md` | 16px | Средние отступы (стандарт) |
| `--gap-lg` | 24px | Большие отступы |

### До:
```css
.player-block {
  gap: var(--gap-lg);  /* 24px - слишком много */
}
```

### После:
```css
.player-block {
  gap: var(--gap-md);  /* 16px - оптимально */
}
```

---

## 📱 Адаптивность статистики

### Desktop (>768px):
```css
.player-stats .stat {
  flex: 1 1 40%;
  padding: 8px 12px;
}
```
**Результат:** 2 колонки по 40%

### Tablet (≤768px):
```css
.player-stats .stat {
  flex: 1 1 40%;
  padding: 8px 10px;  /* Чуть меньше padding */
}
```
**Результат:** Всё ещё 2 колонки, но компактнее

### Mobile (≤480px):
```css
.player-stats .stat {
  flex: 1 1 100%;
  padding: 10px;
}
```
**Результат:** 1 колонка на всю ширину

## 💡 Зачем эти изменения?

### ✅ Gap уменьшен (lg → md)
- Профиль игрока компактнее
- Меньше скролла
- Больше места для контента

### ✅ Статистика на планшетах 40%
- Консистентность с desktop
- Экономия места
- Планшеты достаточно широкие для 2 колонок

### ✅ Меньше padding на планшетах
- `8px 10px` вместо `8px 12px`
- Ещё компактнее
- Лучше использование пространства
