## 🎯 Когда срабатывают анимации

### +EXP:
```javascript
// Когда получаешь опыт
socket.on('playerUpdate', (player) => {
  if (newEXP > oldEXP) {
    const gained = newEXP - oldEXP;
    floatingNumbers.showExpGain(gained);  // ⭐ +25 EXP
  }
});
```

**Примеры:**
- ✅ Выполнил задание → `⭐ +25 EXP`
- ✅ Другой выполнил твоё задание → `⭐ +20 EXP`
- ✅ Админ раздал карты → `⭐ +10 EXP`

---

### -HP:
```javascript
// Когда теряешь жизнь
socket.on('playerUpdate', (player) => {
  if (newHP < oldHP) {
    const lost = oldHP - newHP;
    floatingNumbers.showHpLoss(lost);  // 💔 -40 HP
  }
});
```

**Примеры:**
- ❌ Не выполнил задание → `💔 -40 HP`
- ❌ Другой не выполнил твоё задание → `💔 -40 HP`
- ❌ Таймер истёк → `💔 -40 HP`

---

### +HP:
```javascript
// Когда восстанавливаешь жизнь
socket.on('playerUpdate', (player) => {
  if (newHP > oldHP) {
    const gained = newHP - oldHP;
    floatingNumbers.showHpGain(gained);  // ❤️ +50 HP
  }
});
```

**Примеры:**
- ✅ Хилер вылечил → `❤️ +50 HP`
- ✅ Бонусная карта → `❤️ +30 HP`

---

### Level Up:
```javascript
// Когда повышаешь уровень
socket.on('playerUpdate', (player) => {
  if (newLevel > oldLevel) {
    floatingNumbers.showLevelUp(newLevel);  // 🎉 LEVEL 5!
    sounds.admin();  // Торжественный звук
    vibration.pattern();  // Паттерн вибрации
  }
});
```

**Пример:**
- 🎉 Набрал 100 EXP → `🎉 LEVEL 2!`
- 🎉 Набрал 250 EXP → `🎉 LEVEL 3!`

## 🎨 Технические детали

### Структура кода:

```javascript
class FloatingNumbers {
  // Создать летящую цифру
  createFloatingElement(text, color, icon) {
    const element = document.createElement('div');
    element.innerHTML = `
      <span class="floating-icon">${icon}</span>
      <span class="floating-text">${text}</span>
    `;
    return element;
  }
  
  // Анимировать полёт вверх
  animateFloatUp(element) {
    element.style.transform = 'translate(-50%, -250px) scale(1.5)';
    element.style.opacity = '0';
    setTimeout(() => element.remove(), 1500);
  }
  
  // Анимировать тряску
  animateShake(element, startX, startY) {
    // Трясётся 10 раз
    for (let i = 0; i < 10; i++) {
      setTimeout(() => {
        element.style.left = startX + random(-20, 20) + 'px';
        element.style.top = startY + random(-20, 20) + 'px';
      }, i * 50);
    }
    
    // Потом падает
    setTimeout(() => {
      element.style.transform = 'translate(-50%, 250px) scale(0.5)';
      element.style.opacity = '0';
    }, 500);
  }
}
```

## 📝 Сохранение прогресса (FAQ)

### ❓ Что будет сохраняться?

**БЕЗ сохранения (сейчас):**
```
Закрыл вкладку → ВСЁ СБРОШЕНО
```

**С сохранением (если добавим):**
```
Закрыл вкладку → Уровень, EXP сохранены
Открыл снова → Продолжаешь с того же места
```

### ❓ Как это работает?

```javascript
// Сохраняется в браузере (localStorage)
{
  nickname: "Коля",
  level: 5,
  exp: 200,
  achievements: ["first_task", "level_5"],
  totalLikes: 15
}

// При входе загружается обратно
socket.on('joinSuccess', (player) => {
  const saved = loadProgress(player.nickname);
  if (saved) {
    player.level = saved.level;
    player.exp = saved.exp;
  }
});
```

### ❓ Влияет на игру?

```
НЕТ! ❌
Это только для сохранения между сессиями.
Внутри игры всё работает как обычно.
```
