# 🎨 Исправления дизайна - Статистика и кнопка аватара

## ✅ Что исправлено

### 1. **Статистика игрока** (`.player-stats`)

**Было:** Grid 2 колонки - элементы занимали много места
**Стало:** Flex с wrap - компактное размещение

```css
/* Старый код */
.player-stats {
  display: grid;
  grid-template-columns: repeat(2, 1fr);
  gap: 10px;
}

/* Новый код */
.player-stats {
  display: flex;
  flex-wrap: wrap;
  gap: 8px;
}
```

**Преимущества:**
- ✅ Элементы занимают ровно столько места, сколько нужно
- ✅ Автоматически подстраиваются под размер экрана
- ✅ Меньше отступов (8px вместо 10px)
- ✅ Компактнее padding (10px 14px вместо 12px)

### 2. **Карточка статистики** (`.player-stats .stat`)

```css
.player-stats .stat {
  flex: 1 1 calc(50% - 4px);  /* Занимает 50% ширины */
  min-width: 120px;           /* Минимальная ширина */
  padding: 10px 14px;         /* Уменьшены отступы */
  gap: 8px;                   /* Промежуток между лейблом и значением */
}
```

**Адаптивность:**
- Desktop: 2 колонки (по 50%)
- Tablet/Mobile: 1 колонка (100%)

### 3. **Размеры текста в статистике**

```css
/* Лейбл */
.player-stats .stat-label {
  font-size: 0.75rem;  /* Было 0.8rem */
  white-space: nowrap; /* Не переносится */
}

/* Значение */
.player-stats .stat-value {
  font-size: 0.95rem;  /* Было 1rem */
  white-space: nowrap; /* Не переносится */
}
```

### 4. **Кнопка загрузки аватара** (`.avatar-upload-btn`)

**Проблема:** Кнопка была слишком большой и криво позиционировалась

**Исправления:**
```css
.avatar-upload-btn {
  bottom: -6px;        /* Было -8px - ближе к аватару */
  padding: 3px 8px;    /* Было 4px 10px - компактнее */
  font-size: 0.65rem;  /* Было 0.7rem - меньше текст */
  border-radius: 5px;  /* Было 6px - меньше скругление */
  line-height: 1.2;    /* Новое - контроль высоты строки */
}
```

**Добавлен active state:**
```css
.avatar-upload-btn:active {
  transform: translateX(-50%) translateY(-1px);
}
```
