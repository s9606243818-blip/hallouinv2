## 🎮 Как играть новыми картами

### Актёрские карты (🎭):
```
1. Выбираешь игрока
2. Он показывает (без слов или со звуками)
3. Все угадывают
4. Если угадали → выполнено ✅
```

### Признания (💬):
```
1. Выбираешь игрока
2. Он искренне рассказывает историю
3. Все слушают
4. Если рассказал → выполнено ✅
```

### Игры (🎮):
```
1. Выбираешь 2 игроков
2. Они играют/соревнуются
3. Проигравший пьёт шот
4. Выполнено ✅
```

### Рисование (🎨):
```
1. Выбираешь игрока
2. Он рисует 3 минуты
3. Показывает результат
4. Если нарисовал → выполнено ✅
```

### Акценты/Роли (🗣️🤖):
```
1. Выбираешь игрока
2. Он говорит/ведёт себя в образе 10 минут
3. Если продержался → выполнено ✅
4. Если сорвался → провал ❌
```

### Выкрики (📢):
```
1. Выбираешь игрока
2. Он громко кричит фразу
3. Все слышат
4. Если крикнул → выполнено ✅
```
