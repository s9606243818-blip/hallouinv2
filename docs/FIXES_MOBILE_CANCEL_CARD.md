## 🐛 Исправленные проблемы

### 1. 🚫 Карта "Отмена задания" не работала

**Проблема:**
- Карта была в колоде
- При клике ничего не происходило
- Задание не отменялось

**Причина:**
- В `cardsUI.js` не было обработки типа `cancel_task`
- Карта обрабатывалась только для типов `other` и `both`

**Решение:**
```javascript
// В cardsUI.js - handleCardClick()
if (card.type === 'cancel_task') {
  socket.useActionCard(card.id, null);
  return;
}
```

**Результат:**
- ✅ Карта работает
- ✅ Отменяет последнее задание
- ✅ Отправитель получает -20 HP
- ✅ Задание удаляется у всех участников

### 2. 📱 Игрок отключается при сворачивании приложения

**Проблема:**
- Открыта игра в браузере на телефоне
- Сворачиваешь браузер (открываешь другое приложение)
- Игрок становится "не в сети"
- Приходится заново входить

**Причина:**
- Socket.IO использовал стандартные таймауты:
  - `pingTimeout: 20000` (20 сек)
  - `pingInterval: 10000` (10 сек)
- Мобильные браузеры приостанавливают JavaScript при сворачивании
- За 20 секунд ping не проходит → сервер отключает

**Решение:**

#### Клиент (`socket.js`):
```javascript
this.socket = io({
  // 📱 КРИТИЧНО для мобильных: увеличиваем таймауты
  pingTimeout: 60000,      // 60 сек до отключения
  pingInterval: 25000,     // Проверка каждые 25 сек
  
  // Дополнительные настройки
  forceNew: false,         // Повторно использовать соединение
  multiplex: true,         // Множественные сокеты
});
```

#### Сервер (`server.js`):
```javascript
const io = socketIO(server, {
  // 📱 Настройки для мобильных устройств
  pingTimeout: 60000,      // 60 сек до отключения
  pingInterval: 25000,     // Проверка каждые 25 сек
  cors: {
    origin: "*",
    methods: ["GET", "POST"]
  }
});
```

**Результат:**
- ✅ Игрок остаётся в сети до 60 секунд
- ✅ Можно свернуть приложение на минуту
- ✅ При возврате сразу работает
- ✅ Автопереподключение если всё-таки отключился

---

## 📊 Технические детали

### Таймауты Socket.IO

**До:**
```
pingInterval: 10000  (10 сек)
pingTimeout: 20000   (20 сек)
```

**После:**
```
pingInterval: 25000  (25 сек)
pingTimeout: 60000   (60 сек)
```

**Как это работает:**
1. Сервер отправляет ping каждые 25 секунд
2. Клиент должен ответить pong
3. Если ответа нет 60 секунд → отключение
4. При сворачивании приложения:
   - JS приостановлен на 30-40 сек
   - При возврате JS возобновляется
   - Клиент отправляет pong
   - Соединение остаётся активным
