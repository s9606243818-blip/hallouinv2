# 🎨 Улучшение расположения элементов в профиле игрока

## 📝 Что изменено

### 1. **Player Info - в ряд**
```css

  flex-direction: row;  /* Было: column */
  flex-wrap: wrap;
  align-items: center;
}
```

**Результат:**
```
До:
┌────────────────┐
│ [Аватар]  Имя  │
│           Роль │
└────────────────┘

После:
┌──────────────────┐
│ [Аватар] Имя Роль│  ← Всё в одну строку
└──────────────────┘
```

---

### 2. **Player Header - компактнее**
```css
.player-header {
  gap: var(--gap-md);      /* Было: var(--gap-lg) */
  padding-bottom: 0px;     /* Было: var(--gap-lg) */
}
```

**Результат:** Меньше отступов, компактнее

**Результат на всех устройствах:**

## 🔧 Технические изменения

### Файл: `public/css/player.css`

#### 1. Player Header
```css
/* До */
.player-header {
  gap: var(--gap-lg);        /* 24px */
  padding-bottom: var(--gap-lg); /* 24px */
}

/* После */
.player-header {
  gap: var(--gap-md);        /* 16px */
  padding-bottom: 0px;       /* 0px */
}
```

#### 2. Player Info
```css
/* До */
.player-info {
  flex-direction: column;
}

/* После */
.player-info {
  flex-direction: row;
  flex-wrap: wrap;
  align-items: center;
}
```

#### 3. Player Actions
```css
/* До */
.player-actions button {
  flex: 1;
  min-width: 140px;
}

/* После */
.player-actions button {
  flex: 1 1 auto;
  min-width: 120px;
}
```

#### 4. Avatar Upload Button
```css
/* До */
.avatar-upload-btn {
  position: absolute;
  bottom: -6px;
  left: 50%;
  transform: translateX(-50%);
}

/* После */
.avatar-upload-btn {
  display: inline-flex;
  flex-shrink: 0;
}
```

## 🎨 Элементы в Player Info

### Порядок элементов:
1. **Имя игрока** (h3) - flex-shrink: 1 (сжимается при нехватке места)
2. **Роль** (player-role) - flex-shrink: 0 (не сжимается)
3. **Кнопка аватара** - flex-shrink: 0 (не сжимается)

### Поведение при нехватке места:
```
Достаточно места:
[Имя игрока полностью] [Роль] [📷]

Мало места:
[Имя иг...] [Роль] [📷]  ← Имя обрезается
```
