## 🖼️ Примеры подходящих изображений

### ✅ Поместится (2 МБ и меньше):

- 📷 **Фото с телефона (среднее качество)** - 1-1.5 МБ
- 🎨 **PNG с прозрачностью (небольшое)** - 500 КБ - 1.5 МБ
- 📸 **JPEG высокого качества** - 1-2 МБ
- 🖼️ **Скриншот экрана** - 500 КБ - 1.5 МБ

### ❌ Не поместится (больше 2 МБ):

- 📷 **RAW фото с камеры** - 10-50 МБ
- 🎬 **Кадр из видео 4K** - 3-10 МБ
- 🖼️ **Очень большое изображение** - 5000x5000px
- 📸 **JPEG максимального качества** - 3-5 МБ

---

## 💡 Рекомендации

### Оптимальный размер аватара:
- **Формат:** JPEG или PNG
- **Разрешение:** 500x500 - 1000x1000 px
- **Размер файла:** 200 КБ - 800 КБ
- **Качество:** 80-90%

### Если файл слишком большой:
1. **Уменьшить разрешение** - до 1000x1000px
2. **Снизить качество** - до 80%
3. **Конвертировать в JPEG** - если это PNG
4. **Использовать онлайн компрессор:**
   - TinyPNG.com
   - Squoosh.app
   - CompressJPEG.com

## 🔍 Проверка размера файла

### Windows:
```
1. Правый клик на файл → Свойства
2. Смотрим "Размер"
3. Должно быть ≤ 2 097 152 байт
```

### JavaScript (в коде):
```javascript
const file = event.target.files[0];
const sizeInBytes = file.size;
const sizeInKB = sizeInBytes / 1024;
const sizeInMB = sizeInKB / 1024;

console.log(`Размер: ${sizeInMB.toFixed(2)} МБ`);
```

## 📐 Математика расчёта

### Байты → КБ → МБ:
```
1 КБ = 1024 байт
1 МБ = 1024 КБ = 1,048,576 байт

500 КБ = 500 * 1024 = 512,000 байт
2 МБ = 2 * 1024 * 1024 = 2,097,152 байт
```

### В коде:
```javascript
// Старое значение
const oldLimit = 500 * 1024;  // = 512,000 байт

// Новое значение
const newLimit = 2 * 1024 * 1024;  // = 2,097,152 байт

// Разница
const difference = newLimit - oldLimit;  // = 1,585,152 байт
const timesLarger = newLimit / oldLimit;  // = 4.096 раза
```

Лимит увеличен в **~4 раза**! 🚀

## 🎨 Форматы изображений

### JPEG (.jpg, .jpeg):
- ✅ Разрешено
- 📦 Меньший размер
- 🎨 Хорошо для фото
- ❌ Нет прозрачности

### PNG (.png):
- ✅ Разрешено
- 📦 Больший размер
- 🎨 Хорошо для графики
- ✅ Есть прозрачность

### WebP, GIF, BMP:
- ❌ **НЕ разрешено**
- Нужно конвертировать в JPEG/PNG

## 🎯 Почему именно 2 МБ?

### ✅ Достаточно для:
- Качественных фото с телефона
- PNG с прозрачностью
- Скриншотов экрана
- Обработанных изображений

### ❌ Недостаточно для:
- RAW фото
- Очень больших изображений
- Видео или GIF
- Несжатых файлов

### 💡 Баланс:
- **2 МБ** - золотая середина
- Не слишком мало (как 500 КБ)
- Не слишком много (как 10 МБ)
- Быстро загружается даже на 4G
