# 🎮 Обновление кнопок действий игрока

## ✅ Что изменено

### **Блок `.player-actions`** - кнопки теперь в ряд

#### Было (вертикально):
```css
.player-actions {
  display: flex;
  flex-direction: column;  /* ⬅️ Удалено */
  gap: 10px;
  padding-top: var(--gap-md);
  border-top: 1px solid rgba(255, 255, 255, 0.1);
}

.player-actions button {
  width: 100%;  /* ⬅️ Заменено на flex */
}
```

#### Стало (горизонтально):
```css
.player-actions {
  display: flex;
  flex-wrap: wrap;  /* ⬅️ Добавлено */
  gap: 10px;
  padding-top: var(--gap-md);
  border-top: 1px solid rgba(255, 255, 255, 0.1);
}

.player-actions button {
  flex: 1;           /* ⬅️ Растягиваются равномерно */
  min-width: 140px;  /* ⬅️ Минимальная ширина */
}
```

## 🎯 Как работает

### Desktop (широкий экран):
```css
.player-actions {
  display: flex;          /* Горизонтально */
  flex-wrap: wrap;        /* Перенос на новую строку */
  gap: 10px;
}

.player-actions button {
  flex: 1;                /* Равномерное распределение */
  min-width: 140px;       /* Минимум 140px */
}
```

**Результат:** 
- Если кнопок 2-3: все в один ряд
- Если кнопок 4+: переносятся на следующую строку
- Минимальная ширина кнопки: 140px

### Mobile (≤480px):
```css
.player-actions {
  flex-direction: column;  /* Вертикально */
}

.player-actions button {
  width: 100%;             /* На всю ширину */
}
```

**Результат:** Кнопки идут вертикально одна под другой

## 💡 Преимущества

### ✅ Экономия места по вертикали
- Кнопки не тратят много высоты экрана
- Больше места для карточек и другого контента

### ✅ Удобство использования
- На десктопе все кнопки видны сразу
- Не нужно скроллить вниз

### ✅ Адаптивность
- Автоматически подстраивается под ширину экрана
- На мобильных возвращается к вертикальному виду

### ✅ Гибкость
- `flex: 1` - кнопки растягиваются равномерно
- `min-width: 140px` - не слишком узкие
- `flex-wrap: wrap` - переносятся на новую строку при необходимости

---

## 🔧 Технические детали

### Свойства flex:
```css
flex: 1;
/* Расшифровка: */
flex-grow: 1;      /* Растягивается пропорционально */
flex-shrink: 1;    /* Сжимается при нехватке места */
flex-basis: 0;     /* Стартовый размер 0 (растягивается от минимума) */
```

### Минимальная ширина:
```css
min-width: 140px;
```
- Кнопка не будет уже 140px
- При нехватке места перенесётся на новую строку
- Текст не будет слишком сжат

### Перенос строк:
```css
flex-wrap: wrap;
```
- Если кнопки не помещаются в один ряд
- Автоматически переносятся на следующую строку
- Сохраняют `gap: 10px` между собой

## 📐 Расчёт размещения

### Пример с 3 кнопками на экране 600px:

```
Ширина контейнера: 600px
Gap между кнопками: 10px × 2 = 20px
Доступная ширина: 600px - 20px = 580px

Если все в одну строку:
580px / 3 = ~193px на кнопку ✅ (больше min-width 140px)

Если в две строки:
Строка 1: (600px - 10px) / 2 = 295px на кнопку ✅
Строка 2: 600px на 1 кнопку ✅
```
