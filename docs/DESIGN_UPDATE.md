## 🎯 Ключевые CSS-изменения

### Карточка игрока
```css
.player-item-header {
  display: flex;
  justify-content: space-between;
  align-items: flex-start;
  gap: 12px;
  flex-wrap: wrap;  /* ⭐ Главное исправление! */
}
```

### Информация об игроке
```css
.player-item-info {
  display: flex;
  flex-direction: column;  /* Имя и статы в колонку */
  gap: 6px;
  flex: 1;
  min-width: 0;
}
```

### Роль
```css
.player-item-role {
  align-self: flex-start;  /* Роль сверху справа */
  white-space: nowrap;     /* Не ломается на части */
}
```

## 📐 Схема верстки

```
player-item (flex, gap: 14px)
├── player-item-avatar (56x56px, flex-shrink: 0)
└── player-item-content (flex: 1)
    ├── player-item-header (flex, space-between, wrap)
    │   ├── player-item-info (flex: 1, column)
    │   │   ├── player-item-name
    │   │   └── player-item-stats
    │   └── player-item-role (align-self: flex-start)
    └── like-btn (если доступен)
```
