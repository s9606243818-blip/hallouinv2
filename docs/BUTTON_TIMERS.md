# ⏱️ Таймеры для кнопок запросов

## 📝 Описание

Добавлены таймеры на кнопки запросов (лечение, карты, трек) чтобы предотвратить спам и злоупотребления.

**Ограничения:**
- ❤️ **Лечение** - не чаще чем раз в 5 минут
- 🎴 **Карты** - не чаще чем раз в 5 минут
- 🎵 **Трек** - не чаще чем раз в 5 минут

---

## ✅ Функционал

### 1. **Таймер на кнопке**
После нажатия кнопка блокируется и показывает обратный отсчёт:
```
[  ⏱️ 4:59  ]  → Кнопка недоступна
[  ⏱️ 3:45  ]  → Обратный отсчёт
[  ⏱️ 0:10  ]  → Скоро можно снова
[  Лечение  ]  → Снова доступна!
```

### 2. **Сохранение в localStorage**
Таймеры сохраняются даже при:
- Перезагрузке страницы
- Закрытии вкладки
- Блокировке экрана
- Выходе из игры

### 3. **Визуальная индикация**
```css
/* Обычная кнопка */
background: linear-gradient(135deg, #6366f1, #818cf8);

/* Кнопка с таймером */
background: linear-gradient(135deg, rgba(255, 152, 0, 0.6), rgba(251, 146, 60, 0.6));
opacity: 0.7;
cursor: not-allowed;
```

### 4. **Уведомления**
При попытке нажать заблокированную кнопку:
```
⚠️ Подождите ещё 3:45
```

#### 1. **`public/js/utils/buttonTimers.js`** (новый файл)
Модуль управления таймерами:

```javascript
class ButtonTimers {
  constructor() {
    this.timers = new Map();
    this.cooldowns = {
      heal: 5 * 60 * 1000,    // 5 минут
      cards: 5 * 60 * 1000,   // 5 минут
      music: 5 * 60 * 1000    // 5 минут
    };
  }

  canUse(type) { ... }          // Можно ли использовать
  startTimer(type, btn) { ... } // Запустить таймер
  stopTimer(type, btn) { ... }  // Остановить таймер
  getTimeLeft(type) { ... }     // Осталось времени
}
```

#### 2. **`public/js/main.js`**
Интеграция таймеров в кнопки:

```javascript
if (healBtn) {
  buttonTimers.initButton('heal', healBtn);
  
  healBtn.addEventListener('click', () => {
    // Проверка таймера
    if (!buttonTimers.canUse('heal')) {
      showError(`Подождите ещё ${minutes}:${seconds}`);
      return;
    }
    
    // Отправка запроса
    socket.sendRequestToRole('healer', 'heal');
    
    // Запуск таймера

  });
}
```

## 📊 Механизм работы

### 1. Инициализация
```javascript
// При загрузке страницы
buttonTimers.initButton('heal', healBtn);

// Проверяет localStorage
// Если есть активный таймер - восстанавливает его
```

### 2. Нажатие кнопки
```javascript
healBtn.addEventListener('click', () => {
  // 1. Проверка таймера
  if (!buttonTimers.canUse('heal')) {
    showError('Подождите...');
    return;
  }
  
  // 2. Отправка запроса
  socket.sendRequestToRole('healer', 'heal');
  
  // 3. Запуск таймера на 5 минут
  buttonTimers.startTimer('heal', healBtn);
});
```

### 3. Обратный отсчёт
```javascript
// Каждую секунду обновляется текст кнопки
setInterval(() => {
  const timeLeft = getTimeLeft('heal');
  button.textContent = `⏱️ ${formatTime(timeLeft)}`;
}, 1000);
```

### 4. Завершение
```javascript
// Когда таймер истекает
if (timeLeft <= 0) {
  button.disabled = false;
  button.textContent = 'Лечение'; // Восстанавливает текст
  clearInterval(intervalId);
}
```

## 🔍 API модуля

### Основные методы:

```javascript
// Проверить доступность кнопки
buttonTimers.canUse('heal') 
// → true/false

// Получить оставшееся время (мс)
buttonTimers.getTimeLeft('heal')
// → 245000 (4 минуты 5 секунд)

// Запустить таймер
buttonTimers.startTimer('heal', buttonElement)

// Остановить таймер
buttonTimers.stopTimer('heal', buttonElement)

// Инициализировать кнопку
buttonTimers.initButton('heal', buttonElement)

// Получить статус всех таймеров
buttonTimers.getStatus()
// → { heal: { canUse: false, timeLeft: 245000, ... } }

// Сбросить все таймеры (для отладки)
buttonTimers.resetAll()
```

## ⚙️ Настройка таймеров

Если нужно изменить длительность таймеров, отредактируйте `buttonTimers.js`:

```javascript
this.cooldowns = {
  heal: 5 * 60 * 1000,    // 5 минут
  cards: 3 * 60 * 1000,   // Изменить на 3 минуты
  music: 10 * 60 * 1000   // Изменить на 10 минут
};
```

**Варианты:**
- `1 * 60 * 1000` = 1 минута
- `5 * 60 * 1000` = 5 минут
- `10 * 60 * 1000` = 10 минут
- `30 * 1000` = 30 секунд (для тестирования)
