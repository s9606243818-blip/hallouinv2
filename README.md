# 🎮 Multiplayer Card Game

Многопользовательская карточная игра с ролями, заданиями и системой опыта.

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
npm install
```

### 2. Запуск сервера

```bash
npm start
```

Или для разработки с автоперезагрузкой:

```bash
npm run dev
```

### 3. Открыть в браузере

```
http://localhost:3000
```

## 📋 Возможности

### Основное
- 👥 **Многопользовательская игра** - подключайтесь с друзьями
- 🎴 **50+ карт действий** - разнообразные задания
- 🎭 **Система ролей** - Бармен, Целитель, Дилер, Диджей, Админ
- ⏱️ **Задания с таймерами** - выполняйте задания вовремя
- 🏆 **Система опыта и уровней** - развивайтесь в игре
- 👍 **Лайки** - цените других игроков
- 📸 **Аватары** - загружайте свои изображения

### Роли

#### 👑 Админ (первый игрок или ник с "admin")
- Назначает роли другим игрокам
- Раздает карты всем
- Перезапускает игру
- Имеет специальную колоду админских карт
- Видит кто кого лайкнул

#### 🍺 Бармен
- Наливает напитки себе и другим
- Может налить всем сразу

#### ⚕️ Целитель
- Лечит игроков (+30 HP)
- Может вылечить себя (+20 HP)
- Групповое лечение (+15 HP всем)

#### 🎴 Дилер
- Раздает карты игрокам
- Может взять карту себе
- Раздает карты всем

#### 🎵 Диджей
- Включает музыку (задание для всех)
- Устраивает танцевальные битвы
- Караоке челленджи

## 🎯 Как играть

### Вход в игру
1. Введите свой никнейм
2. Если ник содержит "admin" - вы станете админом
3. При повторном входе ваш профиль восстановится

### Карты
- **На себя** - выполняете сами
- **На другого** - выбираете игрока для задания
- **На двоих** - задание для вас и выбранного игрока
- **На всех** - задание для всех игроков

### Опыт и уровни
- За использование карты: **+5 EXP**
- За выполнение задания: **+20 EXP**
- Каждые **100 EXP** = +1 уровень

### Лайки
- Кликните на игрока в списке чтобы поставить лайк
- Можно лайкнуть каждого игрока только 1 раз
- Лайки сохраняются даже после перезапуска игры

### Задания
- Выполните задание в отведенное время
- Создатель карты нажимает "Выполнено" когда задание сделано
- Если время истекло - задание исчезает без награды

## 📡 Socket.IO события

### Клиент → Сервер
- `join` - вход в игру
- `useActionCard` - использовать карту действия
- `useRoleCard` - использовать карту роли
- `completeTask` - завершить задание
- `likePlayer` - лайкнуть игрока
- `requestCards` - запросить карты у дилера
- `requestHeal` - запросить лечение у целителя
- `adminAssignRole` - назначить роль (админ)
- `adminDealCards` - раздать карты всем (админ)
- `adminResetGame` - перезапустить игру (админ)

### Сервер → Клиент
- `joinSuccess` - успешный вход
- `gameState` - полное состояние игры
- `playerUpdate` - обновление данных игрока
- `playersUpdate` - обновление списка игроков
- `newTask` - новое задание
- `taskComplete` - задание завершено
- `notification` - уведомление в лог
- `error` - ошибка
- `cardRequest` - запрос карт от другого игрока
- `healRequest` - запрос лечения от другого игрока

## 📝 Правила карт

### Карты действий (0-6 на руке)
- Получаете при старте игры
- Можно получить от дилера
- При использовании уходят из руки

### Карты ролей (макс 1 на руке)
- Получаете при назначении роли
- После использования добавляется новая

### Задания
- Создатель карты отмечает выполнение
- При выполнении получатель получает EXP
- Карты на двоих требуют подтверждения обоих

## 💾 Сохранение данных

### Что сохраняется
- Профили игроков (HP, EXP, Level, Лайки)
- При повторном входе профиль восстанавливается

### Что сбрасывается при перезапуске игры
- Карты на руках
- Активные задания
- Роли (кроме админа)

### Что сбрасывается при перезапуске сервера
- Все профили
- Вся игровая сессия

## 🐛 Известные ограничения

- Память профилей хранится только до перезапуска сервера
- Максимум 6 карт действий на руке
- Максимум 1 карта роли на руке
- Один администратор на сервер
- Лайк можно поставить только 1 раз каждому игроку

## 🎮 Советы для игры

1. **Для админа**: Сначала назначьте роли, потом раздайте карты
2. **Для целителя**: Следите за HP игроков
3. **Для дилера**: Помогайте игрокам с картами
4. **Для диджея**: Создавайте веселые задания для всех
5. **Для бармена**: Поддерживайте атмосферу вечеринки
